# KINDpos Terminal Install

## What you need
- Raspberry Pi 5 (this device)
- USB-A to USB-A cable (included)
- CAT5 Ethernet cable (included)

## Install steps

1. Power on the Pi
2. Plug the USB cable: Pi → Terminal
3. When the terminal screen shows **"Allow USB Debugging?"** — tap **Allow**
4. Wait 60 seconds — the terminal will reboot automatically
5. Unplug the USB cable and put it back in the box
6. Plug the CAT5 cable: Pi → Terminal

That's it. KINDpos is now running on your terminal.

## Troubleshooting
- Terminal shows Android home screen: unplug/replug the CAT5 cable
- KINDpos not loading: make sure the Pi is powered on
- Need to add another terminal: plug USB cable into new terminal and repeat steps 2-6
